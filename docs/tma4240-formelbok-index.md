## 2. Lesing per side

### Side 1–2: standard normalfordeling
- **Innhold:** Φ(z) = P(Z ≤ z) for z fra −3,7 til 3,7 med to desimaler.
- **Når:** standardisering med Z = (X − μ)/σ. Sannsynlighet for normal-variabel: P(X ≤ x) = Φ((x − μ)/σ).
- **Forutsetning:** X normalfordelt, eller tilnærmet via CLT (side 38).
- **Må kunne:** Φ(−z) = 1 − Φ(z). Tabellen går bare til 3,7, og for z < −3,7 er verdien ≈ 0.
- **Typisk oppgave:** P(X > a), P(a < X < b), og «finn x med P(X ≤ x) = p» (baklengs oppslag).
- **Eksempel:** X ~ N(10, 4). P(X > 12) = 1 − Φ((12 − 10)/2) = 1 − Φ(1) = 1 − 0,8413 = 0,1587.

### Side 3: kritiske z-verdier
- **Innhold:** z_α med P(Z > z_α) = α. Viktige rader: α = 0,05 gir 1,645; α = 0,025 gir 1,960; α = 0,005 gir 2,576.
- **Når:** konfidensintervall og tosidig test. For 95 % KI bruk z_{0,025} = 1,960.
- **Viktig:** tabellen er gitt for øvre hale.

### Side 4: t-fordeling, kritiske verdier
- **Innhold:** t_{α,ν} med P(T > t_{α,ν}) = α. Kolonnene er α = 0,150–0,0005 og radene er ν = 1–30, 35, 40, 50, 60, 80, 100, 120 og ∞.
- **Når:** σ ukjent: T = (X̄ − μ)/(S/√n) ~ t_{n−1} (side 27).
- **Tosidig 95 %:** bruk kolonnen α = 0,025. Eksempel: t_{0,025,15} = 2,131 og t_{0,025,10} = 2,228.
- **Viktig:** for ν = ∞ er verdiene de samme som z-verdiene.

### Side 5: χ²-fordeling, kritiske verdier
- **Innhold:** χ²_{α,ν} med P(χ² > χ²_{α,ν}) = α for ν = 1–100. Kolonnene er α = 0,995, 0,990, 0,975, 0,950, 0,050, 0,025, 0,010 og 0,005.
- **Når:** variansinferens og KI for σ². Undre grense bruker kolonnen 0,975 (eller 0,995) og øvre grense 0,025 (eller 0,005).
- **Kontroll:** χ²_{0,05,1} = 3,841.

### Side 6–11: F-tabeller
- **Innhold:** P(F > f_{α,ν₁,ν₂}) = α. ν₁ er telleren (kolonner), ν₂ er nevneren (rader).
- **Tabeller:**
  - side 6–7: α = 0,05
  - side 8–9: α = 0,025
  - side 10–11: α = 0,01
- **Når:** to-utvalgs-test av σ₁²/σ₂² (10.8) og KI for variansforhold (9.12).
- **Må kunne:** F_{1−α,ν₁,ν₂} = 1 / F_{α,ν₂,ν₁}. Det står på side 28 og brukes for venstrehalen.
- **Eksempel:** f_{0,05,1,10} = 4,96.

### Side 12–17: binomisk fordeling, P(X ≤ x)
- **Innhold:** kumulativ tabell for n = 2–20, p = 0,05; 0,10; 0,15; 0,20; 0,25; 0,30; 0,40; 0,50; 0,60; 0,70; 0,80; 0,90.
- **Side:** 12 = n 2–8; 13 = n 9–11; 14 = n 12–14; 15 = n 15; 16 = n 16–18; 17 = n 19–20.
- **Når:** P(X = x) = P(X ≤ x) − P(X ≤ x − 1). P(X ≥ x) = 1 − P(X ≤ x − 1).
- **Forutsetning:** uavhengige forsøk med samme p.
- **Viktig:** tabellen gir ikke P(X = x) direkte. Trekk fra forrige rad.
- **Eksempel:** n = 10, p = 0,30: P(X = 2) = 0,2335 (beregnet: 45 · 0,3² · 0,7⁸).
- **Typisk oppgave:** minst én eller høyst x av n, «minst én som ikke ror», sjekk av n og p.

### Side 18–20: Poissonfordeling, P(X ≤ x)
- **Innhold:** μ = 0,1–0,9 og 1,0–5,0 (side 18), 5,5–9,5 (side 19) og 10–18 (side 20).
- **Når:** antall hendelser per tidsenhet eller grense for binomisk med stor n og lite p. μ = np (side 31).
- **Eksempel:** μ = 2: P(X ≤ 1) = 0,4060 (side 18).

### Side 21–22: hypergeometrisk fordeling
- **Ikke pensum** (5.3 er utelatt i pensum). Ikke bruk til eksamen. Siden er tatt med for fullstendighet.

### Side 23–24: Wilcoxon-tabeller
- **Ikke pensum.** Pensum dekker 16.1 (fortegnstesten) til eksempel 16.2. Wilcoxon-tabellene hører til senere deler av kapittel 16. Ikke bruk.

### Side 25: diskrete fordelinger

| Fordeling | Formel | E(X) | Var(X) | Merk |
|---|---|---|---|---|
| Binomisk b(x; n, p) | C(n, x) pˣ (1 − p)ⁿ⁻ˣ, x = 0,…,n | np | np(1 − p) | Brukes med tabell side 12–17 |
| Poisson p(x; μ) | μˣ e^(−μ) / x!, x = 0,1,… | μ | μ | Brukes med tabell side 18–20 |
| Hypergeometrisk h(x; N, n, k) | (k over x)(N−k over n−x)/(N over n) | nk/N | ((N−n)/(N−1)) · n · (k/N)(1 − k/N) | **Ikke pensum** |
| Geometrisk g(x; p) | p(1 − p)^(x−1), x = 1,2,… | 1/p | (1 − p)/p² | x er antall forsøk til første suksess |
| Negativ binomisk b*(x; k, p) | (x−1 over k−1) pᵏ (1 − p)^(x−k), x = k, k+1,… | k/p | k(1 − p)/p² | x er antall forsøk til k-te suksess; k = 1 gir geometrisk |

- **Forutsetning:** uavhengige forsøk med konstant p.
- **Må kunne:** geometrisk og negativ binomisk teller forsøk (x fra 1 eller fra k), ikke feil. Sjekk om oppgaven spør om antall feil eller antall forsøk.

### Side 26: diskret uniform, multinomisk, normal, eksponential
- **Diskret uniform:** f = 1/k på x₁,…,x_k. E(X) = (1/k) Σ xᵢ.
- **Multinomisk:** f = n!/(x₁!⋯x_k!) · p₁^x₁ ⋯ p_k^x_k, Σxᵢ = n. E(Xᵢ) = npᵢ, Var(Xᵢ) = npᵢ(1 − pᵢ), Cov(Xᵢ, Xⱼ) = −npᵢpⱼ. Med k = 2 er X₁ binomisk.
- **Normal N(μ, σ²):** f(x) = (1/(√(2π)σ)) exp(−(x − μ)²/(2σ²)). E = μ, Var = σ², F(x) = Φ((x − μ)/σ).
- **Eksponensial (β-parametrisering):** f(x) = (1/β) e^(−x/β), x ≥ 0. E = β, Var = β². λ = 1/β. Forelesningsnotatene bruker samme β.
  - **Må kunne:** F(x) = 1 − e^(−x/β) (ikke i boka). Med tabell: P(X > x) = e^(−x/β).

### Side 27: χ² og t
- **χ²_ν:** E = ν, Var = 2ν. Kommentar: Σ((Xᵢ − μ)/σ)² ~ χ²_n. (n−1)S²/σ² ~ χ²_(n−1), og X̄ og Σ(Xᵢ − X̄)² er uavhengige.
- **t_ν:** E = 0 for ν ≥ 2, Var = ν/(ν − 2) for ν ≥ 3. Z/√(V/ν) ~ t_ν når Z og V er uavhengige.
- **Typisk bruk:** (X̄ − μ)/(S/√n) ~ t_(n−1) når Xᵢ er normale.
- **Må kunne:** t_1 er Cauchy, og t_ν → N(0,1) når ν → ∞.

### Side 28: Gamma, Weibull, F, kontinuerlig uniform
- **Gamma(α, β):** f(x) = x^(α−1) e^(−x/β) / (β^α Γ(α)), x ≥ 0. E = αβ, Var = αβ², M(t) = (1 − βt)^(−α) for t < 1/β.
  - α = 1 gir eksponensial. α = ν/2 og β = 2 gir χ²_ν.
- **Weibull:** f(x) = αβ x^(β−1) e^(−αx^β). Parametrisering er ikke pensum; hold deg til oppgavens definisjon.
- **F(ν₁, ν₂):** E = ν₂/(ν₂ − 2) for ν₂ ≥ 3, Var for ν₂ ≥ 5. Kommentar: (χ²_ν₁/ν₁)/(χ²_ν₂/ν₂) ~ F(ν₁, ν₂) når de er uavhengige. Gir f_(α,ν₁,ν₂) = 1/f_(1−α,ν₂,ν₁).
- **Kontinuerlig uniform U(a, b):** f = 1/(b − a), E = (a + b)/2, Var = (b − a)²/12.

### Side 29–30: ikke pensum
- Beta, Pareto, lognormal, Cauchy, Laplace (side 29), logistisk, invers Gauss, invers gamma og multinormal (side 30). Ikke pensum. Multinormal er bare nevnt her fordi den står i samme boka.

### Side 31: sammenhenger mellom fordelinger
- **Innhold:** diagram som viser transformasjoner (heltrukne linjer) og grenseverdier (stiplede linjer).
- **Nyttige linjer for pensum:**
  - binomisk → Poisson: μ = np, n → ∞
  - binomisk → normal: μ = np, σ² = np(1 − p), n → ∞
  - Poisson → normal: μ → ∞
  - gamma med α = 1 gir eksponensial, og α = ν/2, β = 2 gir χ²
  - Σ Xᵢ for uavhengige Poisson gir Poisson (μ = Σμᵢ)
  - X₁/X₂ for uavhengige normal gir Cauchy
- **Bruk:** oversikt for tema 5, 6 og 7. Ikke en eksamensformel i seg selv.

### Side 32: sannsynlighet og kombinatorikk
- **Addisjon:** P(A₁ ∪ … ∪ Aₙ) = Σ P(Aᵢ) − Σ P(Aᵢ ∩ Aⱼ) + Σ P(Aᵢ ∩ Aⱼ ∩ Aₖ) − … (inkl.-ekskl.). For to hendelser: P(A ∪ B) = P(A) + P(B) − P(A ∩ B).
- **Multiplikasjon:** P(A₁ ∩ … ∩ Aₙ) = P(A₁)P(A₂|A₁)⋯P(Aₙ|A₁ ∩ … ∩ Aₙ₋₁).
- **Total sannsynlighet:** P(A) = Σ P(A|Bᵢ)P(Bᵢ) for en partisjon B₁,…,B_k.
- **Bayes:** P(B_r|A) = P(A|B_r)P(B_r) / Σ P(A|Bᵢ)P(Bᵢ). Første ledd er P(B_r|A) = P(B_r ∩ A)/P(A), så betinget sannsynlighet er inkludert.
- **Dobbel forventning og varians:** E(X) = E(E(X|Y)), Var(X) = E(Var(X|Y)) + Var(E(X|Y)).
- **Kombinatorikk:** n! antall permutasjoner. nPr = n!/(n − r)! ordnet utvalg uten tilbakelegging. (n r) = n!/(r!(n − r)!) uordnet utvalg.
- **Må kunne:** komplementregel P(Aᶜ) = 1 − P(A). Uavhengighet P(A ∩ B) = P(A)P(B). Ikke i boka; det må du kunne utenat.

### Side 33: kovarians, korrelasjon, MGF og spesialfunksjoner
- **Kovarians:** Cov(X, Y) = E(XY) − E(X)E(Y).
- **Korrelasjon:** ρ(X, Y) = Cov(X, Y)/√(Var(X)Var(Y)).
- **MGF:** M_X(t) = E(e^(tX)).
- **Γ og B:** Γ(α) = ∫₀^∞ t^(α−1) e^(−t) dt. Γ(α) = (α − 1)Γ(α − 1), Γ(n + 1) = n!, Γ(1/2) = √π. B(x, y) = Γ(x)Γ(y)/Γ(x + y).
- **Rekker:** Σ (n k) aᵏ bⁿ⁻ᵏ = (a + b)ⁿ, Σ aᵏ/k! = eᵃ, Σ_{k=0}ⁿ aᵏ = (1 − aⁿ⁺¹)/(1 − a), Σ k = n(n+1)/2, Σ k² = n(n+1)(2n+1)/6.

### Side 34: funksjoner og lineærkombinasjoner
- **E(X) for ikke-negative:** diskret E(X) = Σ_{k≥0} P(X > k). Kontinuerlig E(X) = ∫₀^∞ P(X > x) dx.
- **Transformasjon, én variabel:** Y = u(X) monoton med invers X = w(Y). Da er g(y) = f(w(y)) · |w′(y)|.
- **Transformasjon, to variabler:** g(y₁, y₂) = f(w₁, w₂) · |J|, der J er Jacobi-determinanten.
- **Lineærkombinasjon:** Y = Σ aᵢXᵢ + b. E(Y) = Σ aᵢE(Xᵢ) + b. Var(Y) = Σ aᵢ² Var(Xᵢ) + 2 Σ_{i<j} aᵢaⱼ Cov(Xᵢ, Xⱼ).
- **Må kunne:** transformasjonsformelen krever monotonisitet. Hvis u ikke er monoton, må du dele i intervaller.

### Side 35: fordeling av lineærkombinasjoner og delta-metoden
- **Normal:** Σ aᵢXᵢ ~ N(Σ aᵢμᵢ, Σ aᵢ²σᵢ²) for uavhengige normalvariabler.
- **Binomisk:** Σ Xᵢ er binomisk med Σ mᵢ og p når Xᵢ har samme p.
- **Poisson:** Σ Xᵢ er Poisson med μ = Σ μᵢ.
- **χ²:** Σ Xᵢ er χ² med Σ νᵢ frihetsgrader.
- **E[g(X)]:** Σ g(x) f(x) (diskret) eller ∫ g(x) f(x) dx (kontinuerlig).
- **Delta-metoden:** E[g] ≈ g(μ), og Var[g] ≈ Σ (∂g/∂μᵢ)² Var(Xᵢ) + 2 Σ_{i<j} (∂g/∂μᵢ)(∂g/∂μⱼ) Cov(Xᵢ, Xⱼ).
- **Chebyshev:** P(|X − μ| < kσ) ≥ 1 − 1/k². Står i boka, men ikke i pensum (Kap 4.4). Ikke sikker på eksamensbruk.

### Side 36: regresjon og variansanalyse
- **Enkel lineær regresjon:** E(Yᵢ) = α + βxᵢ. β̂ = Σ(xᵢ − x̄)(Yᵢ − Ȳ)/Σ(xᵢ − x̄)², α̂ = Ȳ − β̂x̄.
- **Variansestimator:** S² = (1/(n − 2)) Σ(Yᵢ − α̂ − β̂xᵢ)². Når Yᵢ er normale: (n − 2)S²/σ² ~ χ²_(n−2), og den er uavhengig av α̂ og β̂.
- **Pensum:** regresjonsdelen er pensum (11.1–11.6). Variansanalyse (Q₀, Q₁) er ikke pensum.
- **Cauchy-Schwarz og Jensen:** ikke pensum.

### Side 37: ikke pensum
- χ²-test for tilpasning (Σ(Xᵢ − npᵢ)²/(npᵢ) ~ χ²_(k−1)), Wilcoxon-tegnrangtest og -rangsumtest, Mann-Whitney. Ikke pensum.

### Side 38: grenseresultater
- **Konvergens i sannsynlighet og i fordeling:** definisjoner. Pensum bare som støtte.
- **Konsistens:** θ̂ er konsistent når E(θ̂) → θ og Var(θ̂) → 0. Pensum (estimering, 9.x).
- **Sentralgrenseteoremet:** (X̄ − μ)/(σ/√n) er tilnærmet N(0, 1) for store n. Pensum (8.4).
- **Slutskys setning:** ikke eksplisitt pensum.

### Side 39: Cramérs setning
- Ikke pensum.

## 3. Hva må kunnes utenat (ikke i formelboka)

Dette er ikke i formelboka, og det må du forstå eller huske selv:

- **Sannsynlighetsaksiomer og komplement:** P(A) ∈ [0, 1], P(Aᶜ) = 1 − P(A), uavhengighet P(A ∩ B) = P(A)P(B).
- **Uniform sannsynlighetsmodell:** P(A) = |A|/|S|.
- **Simultan-, marginal- og betinget fordeling:** f(x, y), f_X(x) = Σ_y f(x, y), f(x|y) = f(x, y)/f_Y(y).
- **Generelle definisjoner:** E(X) = Σ x f(x) eller ∫ x f(x) dx, Var(X) = E(X²) − μ².
- **MGF-egenskaper:** M_{X+Y}(t) = M_X(t)M_Y(t) for uavhengige X og Y. Ingen MGF-tabell i boka.
- **Inversjonsmetoden:** X = F⁻¹(U) med U ~ U(0,1). For eksponensial β: X = −β ln(1 − U) (forelesning, uke 3).
- **Poisson-approksimasjon til binomisk:** tommelfingerregel n ≥ 20 og p ≤ 0,05 (Walpole 5.6), ikke i boka.
- **Standardfeil for proporsjon:** SE(p̂) = √(p̂(1 − p̂)/n).
- **Stikkprøvestørrelse:** n ≥ (zσ/E)² for ønsket feilmargin E.
- **Prediksjonsintervall:** x̄ ± t·S·√(1 + 1/n).
- **Tosidig test og KI-dualitet:** P-verdi og konfidensintervall gir samme konklusjon.
- **Teststyrke for z-test (høyresidig):** β = Φ(z_α − δ√n/σ), der δ = μ₁ − μ₀.
- **Fortegnstesten:** antall positive differanser er Bin(n, 1/2) under H₀ (bruk tabell side 12–17, kolonne p = 0,50).
- **Permutasjonstest:** eksakt p-verdi ved å telle permutasjoner (E 3, 4.2).
- **MLE:** maksimere log-sannsynlighet. Eksponensial: β̂ = x̄. Normal: μ̂ = x̄, σ̂² = (1/n)Σ(xᵢ − x̄)².
- **Regresjon:** Sxx = Σ(xᵢ − x̄)², Sxy = Σ(xᵢ − x̄)(yᵢ − ȳ), β̂ = Sxy/Sxx. SE(β̂) = S/√Sxx.
